# Bus Booking App Design System v1.0

## Brand Personality

The application should feel:

* Premium
* Reliable
* Modern
* Safe
* Professional
* Comfortable

Keywords:
Travel • Trust • Simplicity • Premium Mobility

Avoid:

* Bright startup colors
* Excessive gradients
* Material Design defaults
* Overcrowded screens
